# Fiuu Android XDK sample

Sample host app. It does not compile the SDK.

## Dependency

```kotlin
implementation("com.github.fiuu-mobile:Mobile-XDK-Fiuu_Android_Library:4.0.0")
```

`maven("https://jitpack.io")` is in this project's dependency repositories. JitPack installs the 4.0.0 GitHub Release zip (`Mobile-XDK-Fiuu_Android_Library-4.0.0.zip`). The published POM carries the library's transitive dependencies.
